### 📋 Présentation

**Smart Collect** simplifie la saisie et la structuration d'informations tabulaires sans nécessiter de connexion Internet. L'application conserve les données localement sur votre terminal et permet la synchronisation sur votre compte Google Drive personnel (`drive.file`) sans aucun serveur tiers.

---

### ⚡ Fonctionnalités

| Module | Description |
| :--- | :--- |
| 📊 **Tableaux personnalisés** | Création de tables avec champs textes, numériques, indicatifs téléphoniques internationaux et menus déroulants. |
| 🏷️ **Gestion de l'obligation** | Préfixez un nom de champ par `@` (ex: `@Email`) pour le rendre facultatif. Tous les autres champs sont requis. |
| 📅 **Suivi & Rendez-vous** | Planification, rappels d'échéances et historique d'appels par entrée. |
| 📞 **Actions directes** | Déclenchement d'appels téléphoniques ou ouverture de conversations WhatsApp en 1 clic. |
| 🖨️ **Impression PDF** | Génération de rapports personnalisés (Portrait / Paysage, réglage de police, filtres sélectifs). |
| 📑 **Compatibilité Excel** | Export de modèles vierges et import direct depuis des fichiers `.xlsx`. |
| 🔒 **Sécurité renforcée** | Binaire compilé avec offuscation Dart (`--obfuscate`) pour protéger le code source. |
